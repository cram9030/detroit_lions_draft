# Draft Class Surplus AV

This document describes the surplus AV metric and how to use the
`draft_class_surplus_av.py` script to evaluate any team's draft class.

---

## Metric overview

**Surplus AV** measures how much more (or less) value a player delivered
compared to what a team should historically expect from that pick position,
both measured relative to replacement level.

```
total_4yr_av_above_replacement(player) = total_4yr_av(player) − replacement_level
surplus_av(player)   = total_4yr_av_above_replacement(player) − eavar[player.pick]
class_surplus_av     = Σ surplus_av(player) across all picks in the class
```

| Term | Meaning |
|---|---|
| `total_4yr_av` | Sum of the player's actual/projected AV over the first four seasons of their career (years 0–3 from their draft year) |
| `total_4yr_av_above_replacement` | `total_4yr_av` minus the replacement-level baseline (a 4-year total, ≈ 4.6 AV) |
| `eavar` | Expected AV Above Replacement for that pick number, from `data/processed/expected_av_above_replacement.csv` |
| `surplus_av` | Positive = outperformed pick expectations; negative = underperformed |

Both sides of the comparison are expressed in "above replacement" units, so
a player who matches replacement-level output has `total_4yr_av_above_replacement ≈ 0`
regardless of their draft position.  Picks beyond pick 250 (the last entry in
the EAVAR table) are assigned the pick-250 EAVAR as a conservative floor.

The EAVAR table (`expected_av_above_replacement.csv`) is generated by the
analysis pipeline (`scripts/run_analysis.py`) and stores five columns:
`pick`, `eavar`, `eavar_upper`, `eavar_lower`, `replacement_level`.

---

## Observed vs projected seasons

The script uses as many observed seasons as are available:

| Seasons with data | Projected years |
|---|---|
| 2 (rookie + yr2) | years 2 and 3 via model |
| 3 | year 3 via model |
| 4 | none — fully observed |

The minimum input requirement is **two completed seasons**.  Draft classes
with fewer than two seasons of data (e.g. the most recent draft year) are
rejected with a descriptive error.

---

## Prerequisites

1. **Draft data** — at least two Stathead parquets for the target draft year:

   ```
   data/raw/stathead/annual_av/draft{YEAR}_season{YEAR}.parquet
   data/raw/stathead/annual_av/draft{YEAR}_season{YEAR+1}.parquet
   ```

   Download via:
   ```bash
   python src/stathead_downloader.py --config config/stathead_annual_av.json
   ```

2. **Trained model** (required when fewer than 4 seasons are observed):

   ```bash
   python scripts/train_models.py --model parametric   # default
   python scripts/train_models.py --model knn
   python scripts/train_models.py --model ridge
   ```

3. **EAVAR table** — generated by the full analysis pipeline:

   ```bash
   python scripts/run_analysis.py
   ```

---

## Usage

```bash
# Basic — uses parametric model by default
python scripts/draft_class_surplus_av.py --team DET --year 2024

# With a different model
python scripts/draft_class_surplus_av.py --team DET --year 2024 --model knn

# Custom output directory
python scripts/draft_class_surplus_av.py --team DET --year 2024 --output-dir /tmp/charts
```

### Arguments

| Argument | Required | Default | Description |
|---|---|---|---|
| `--team` | yes | — | Three-letter team code (e.g. `DET`, `KC`, `PHI`) |
| `--year` | yes | — | Draft year (e.g. `2024`) |
| `--model` | no | `parametric` | One of `parametric`, `knn`, `ridge` |
| `--models-dir` | no | `models/` | Path to trained model artifacts |
| `--output-dir` | no | `outputs/figures/` | Directory to write HTML charts |

## Outputs

### Console

A per-player table showing observed and projected season AV alongside
the EAVAR baseline and individual surplus:

```
Player            | Pos | Pick | obs_yr0 | obs_yr1 | proj_yr2 | proj_yr3 | total_4yr_av | total_4yr_av_above_replacement | eavar | surplus_av | is_projected
Terrion Arnold    | CB  |  24  |   10.0  |  12.0   |   8.2    |   7.5    |    37.7      |              33.1              | 15.1  |   +18.0    | True
...
Class totals (10 players, 10 projected):
  Total 4yr AV         : 184.3
  Total above repl.    : 138.3
  Total EAVAR          : 148.6
  Class surplus        : -10.3
```

### Charts

Two interactive HTML files saved to `outputs/figures/` (or `--output-dir`):

- **`{TEAM}_{YEAR}_player_surplus_av.html`** — grouped bar chart comparing
  each player's total 4-year AV against their EAVAR baseline.
- **`{TEAM}_{YEAR}_class_surplus_av.html`** — per-player surplus bars
  (green = positive, red = negative) with the class total in the title.

## Python API

The public functions in `src/surplus_av.py` can be used directly:

```python
from pathlib import Path
from src.surplus_av import (
    load_team_draft_class,
    aggregate_observed_av,
    aggregate_model_av,
    compute_surplus_av,
)
from src.models.factory import make_career_av_model

draft_df = load_team_draft_class("DET", 2024)

# If all 4 seasons have been played (years_from_draft == 3 present):
players_df = aggregate_observed_av(draft_df)

# Otherwise project missing seasons with a trained model:
model = make_career_av_model("parametric")
model.load(Path("models/parametric"))
players_df = aggregate_model_av(draft_df, model)

results = compute_surplus_av(players_df)
print(results.select(["Player", "Pick", "total_4yr_av", "total_4yr_av_above_replacement", "eavar", "surplus_av"]))
```

## Expansion notes

- **CBA-specific EAVAR**: the replacement level and expected AV curves may
  shift across collective bargaining agreements.  A future version will allow
  specifying a year range for the EAVAR table to match the CBA under which the
  draft class was signed.
- **Executive attribution**: once CBA-adjusted EAVAR is in place, individual
  picks (and their surpluses) can be rolled up by the GM/executive in charge to
  produce a personnel-level evaluation.
