# GM Draft and Trade Performance

Two scripts assess General Manager performance across draft surplus AV and trade value:

| Script | Anchor | Use case |
|---|---|---|
| `scripts/gm_comparison.py` | Specific team + year | Compare a target GM against all peers whose tenures overlap |
| `scripts/all_gm_performance.py` | Date range | Survey every GM active during a given window |

Both scripts produce three HTML charts and a console summary table.

---

## Prerequisites

1. **Stathead AV parquets** — `data/raw/stathead/annual_av/*.parquet`  
   Fetch with `python src/stathead_downloader.py --config config/stathead_annual_av.json` (requires `secrets/cookies.json`).

2. **PFR executives parquets** — `data/raw/pfr/executives/{team}_executives.parquet`  
   Fetch with `python src/pfr_downloader.py --config config/pfr_executives.json` (no auth required).

3. **Trained career AV model** — artifacts in `models/linear/`, `models/knn/`, `models/ridge/`, or `models/parametric/`  
   Train with `python scripts/train_models.py --model linear` (or `all`).

4. **EAVAR table** — `data/processed/expected_av_above_replacement.csv`  
   Generated by `python scripts/run_analysis.py` (or `python scripts/expected_av_above_replacement.py`).

5. **Trade data** — `data/processed/` trade parquets  
   Generated by `python scripts/run_analysis.py`.

## `gm_comparison.py`

Finds the GM for a given team and year, then locates all other GMs whose tenures overlap that GM's tenure. Useful for a head-to-head peer comparison anchored to a specific GM.

### Arguments

| Argument | Default | Description |
|---|---|---|
| `--team` | `DET` | Stathead team code |
| `--year` | `2024` | Draft year used to identify the target GM |
| `--model` | `linear` | Career AV model (`parametric`, `knn`, `linear`, `ridge`) |
| `--parametric-curve` | `quadratic` | Curve variant when `--model=parametric` |
| `--chart` | `eaar` | Trade chart column prefix |
| `--output-dir` | `outputs/gm_comparison` | Directory for HTML output |
| `--data-end-year` | `2024` | Last draft year with ≥2 completed seasons |

### Examples

```bash
python scripts/gm_comparison.py                          # DET 2024 defaults
python scripts/gm_comparison.py --team KAN --year 2022
python scripts/gm_comparison.py --team NWE --year 2019 --model knn
python scripts/gm_comparison.py --year 2022 --chart rich_hill
```

### Output files

```
outputs/gm_comparison/{TEAM}_{YEAR}_gm_quadrant.html
outputs/gm_comparison/{TEAM}_{YEAR}_gm_draft_bar.html
outputs/gm_comparison/{TEAM}_{YEAR}_gm_trade_bar.html
```

## `all_gm_performance.py`

Finds every GM whose tenure overlaps a user-supplied date range. No team lookup is performed — the date range is applied directly as the overlap window. Useful for a full-league survey over an era.

### Arguments

| Argument | Default | Description |
|---|---|---|
| `--from-year` | `2001` | Start of the overlap window |
| `--to-year` | `2024` | End of the overlap window |
| `--model` | `linear` | Career AV model (`parametric`, `knn`, `linear`, `ridge`) |
| `--parametric-curve` | `quadratic` | Curve variant when `--model=parametric` |
| `--chart` | `eaar` | Trade chart column prefix |
| `--output-dir` | `outputs/gm_performance` | Directory for HTML output |
| `--data-end-year` | `2024` | Last draft year with ≥2 completed seasons |
| `--data-start-year` | `2010` | Floor of each GM's assessed period (Stathead data availability) |

### Examples

```bash
python scripts/all_gm_performance.py                          # all GMs 2001–2024
python scripts/all_gm_performance.py --from-year 2010 --to-year 2024
python scripts/all_gm_performance.py --model knn --chart rich_hill
python scripts/all_gm_performance.py --from-year 2015 --to-year 2024 --model linear
```

### Output files

```
outputs/gm_performance/{from_year}_{to_year}_gm_quadrant.html
outputs/gm_performance/{from_year}_{to_year}_gm_draft_bar.html
outputs/gm_performance/{from_year}_{to_year}_gm_trade_bar.html
```

## Output charts

### Quadrant scatter (`*_gm_quadrant.html`)

Each GM is plotted as their team's logo. X-axis: average draft surplus AV per year. Y-axis: average trade EAVAR per year. Dotted lines at x=0 and y=0 divide the plot into four quadrants:

| Quadrant | Meaning |
|---|---|
| Top-right | Strong drafting **and** good trade value — elite |
| Top-left | Good trade value, below-average drafting |
| Bottom-right | Strong drafting, below-average trade value |
| Bottom-left | Below average on both dimensions |

### Draft surplus bar chart (`*_gm_draft_bar.html`)

Horizontal bars ranked by average draft surplus AV per year (highest at top). Each bar is colored with the team's primary color; the team logo appears at the tip of the bar.

### Trade value bar chart (`*_gm_trade_bar.html`)

Same layout as the draft surplus bar, ranked by average trade EAVAR per year.

## Console summary table

Both scripts print a ranked table to stdout:

```
GM                             Team    Assessed  Surplus/Yr   EAVAR/Yr
--------------------------------------------------------------------------
John Schneider                 SEA     2010–2024       8.23       3.14
...
```

`Assessed` is the window for which data was actually available (floored at `--data-start-year`, capped at `--data-end-year`), which may be narrower than the GM's full tenure.

## Interpretation notes

**`--from-year` vs. `--data-start-year`** (`all_gm_performance.py` only)  
`--from-year` controls *which GMs are included* — any GM whose tenure overlaps that window appears in the results. `--data-start-year` controls the *floor of the assessed period* for each GM. A GM active in 2001 with `--data-start-year=2010` (the default) will appear in the results but their draft classes before 2010 won't be scored. Set `--data-start-year=2001` only if you have Stathead data going back that far.

**Cincinnati Bengals caveat**  
PFR records Duke Tobin (the Bengals' de-facto GM) as "Director of Player Personnel" rather than "General Manager." The filtering logic excludes non-GM titles, so the Bengals will not appear in any output.

**Draft years with < 2 completed seasons**  
Recent draft classes (where players have played fewer than 2 seasons) are excluded from surplus AV calculations because projected values would be unreliable. These classes are counted but not scored; GMs with *only* recent classes are excluded entirely by `filter_gm_records`.
