# Draft-to-Performance Correlation

`scripts/draft_performance_correlation.py` measures whether draft quality
predicts on-field success using two complementary methods.

---

## Methods

### Lagged Draft Class Correlation

For each draft class (year Y) and lag k ∈ {0, 1, 2, 3}, compute the Pearson r
and Spearman ρ between a team's draft class quality and their performance in
season Y+k.

**Question answered:** Does drafting well in year Y lead to winning more games
k years later?

**Draft metrics evaluated:**

| Metric | Description |
|---|---|
| `class_surplus` | Surplus AV — how much the class outperformed pick-position expectations |
| `trade_av` | Net EAVAR value gained/lost via draft pick trades for that class year |
| `net_av` | `class_surplus + trade_av` — combined drafting and trading quality |

**Season performance metrics:** win %, point differential, SRS (Simple Rating System)

**Outputs:**
- Console table of Pearson r and Spearman ρ for every (metric, lag, performance) combination
- `outputs/figures/draft_lag_correlation_heatmap.html` — heatmap of Pearson r across all combinations
- `outputs/figures/draft_lag_{metric}_vs_{perf}.html` — 2×2 scatter grids (one per metric pair), one subplot per lag

---

### Composite Active Roster Draft Value

For each (team, season Y), aggregate the in-season AV contribution of all
recently-active draft classes:

```
composite_av(Y) = obs_yr0(class Y) + obs_yr1(class Y−1) + obs_yr2(class Y−2) + obs_yr3(class Y−3)
```

Then correlate `composite_av` against that season's win %, point differential,
and SRS.

**Question answered:** Do teams that get more total production from recent draft
picks perform better in the same season?

**Output:**
- Console table of Pearson r and Spearman ρ for each performance metric
- `outputs/figures/draft_approach2_composite_scatter.html` — 1×3 scatter with trend lines

## Prerequisites

- **Baked draft data** — JSON files in `data/processed/baked/draft_{year}.json`,
  generated by `scripts/baked_draft_data.py`
- **nflreadpy** — for schedule data (season performance) and trade history
- **Trained model** — only needed to regenerate baked data; not required at
  correlation runtime

---

## Usage

```bash
# Default: 2000–2024 draft classes
python scripts/draft_performance_correlation.py

# Restrict to more recent classes
python scripts/draft_performance_correlation.py --min-year 2010
```

### Arguments

| Argument | Default | Description |
|---|---|---|
| `--min-year` | `2000` | Earliest draft class year to include |

---

## Season performance computation

Win % and point differential are computed directly from nflreadpy regular-season
schedules. SRS (Simple Rating System) is solved via a linear system: each team's
SRS equals its average margin of victory adjusted for opponent quality, with the
constraint that all SRS values sum to zero per season.

---

## Trade value attribution

Trade AV (`trade_av`) uses the EAVAR chart (`data/processed/eavar.csv`) to value
picks. Trades are filtered to `pick_season == draft_year` so that picks are
attributed to the draft class they belong to, regardless of when the trade was
executed. Net value = received picks − gave picks, converted to EAVAR units.

See [`trade-analysis.md`](trade-analysis.md) for the full trade value framework.
